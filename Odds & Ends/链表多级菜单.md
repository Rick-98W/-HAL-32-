### 多级菜单概述

多级菜单是一种用于在嵌入式系统中展示复杂功能的用户界面设计模式，能够在**有限的显示空间**内通过**层次化结构**组织大量选项。它通过分级展示不同菜单项，使得用户在逐层浏览中找到目标功能或设置项，极大地提升了用户体验和设备操作的便捷性。

---

### 多级菜单的特点

1. **分层结构**：多级菜单通过将功能分层，使信息结构更清晰。在最顶层通常显示主要功能项，如“设置”、“状态”等，选择某一项后进入其下的子菜单，子菜单项可以进一步被划分成更多子功能或操作选项。

2. **层次化导航**：在导航过程中，用户可以通过按键依次浏览每一层级的菜单项，这使得嵌入式设备可以在有限显示空间内提供更为复杂的功能集。

3. **信息整合与简化**：多级菜单将庞杂的内容按层级显示，避免了在一个界面中堆叠过多内容，从而保证界面的简洁性和易读性。

4. **节省资源**：相比一次性展示所有内容的单级菜单，分层的多级菜单只需显示当前所在层级的选项，这对**内存资源有限的嵌入式设备**而言尤为重要。

---

### 多级菜单的典型应用场景

多级菜单在各种嵌入式系统中有广泛应用，尤其是在以下场景中：

1. **工业控制设备**：如工厂控制面板上的设置菜单、生产参数调整菜单等，方便操作员在各种状态和参数之间切换。
2. **家用电器**：如洗衣机、微波炉等设备的功能选择菜单，用于操作模式选择、定时设置、温度调节等。
3. **医疗设备**：用于显示各种监测数据、调节监测参数或进入设备维护菜单。
4. **手持设备**：如检测仪器、遥控器等设备，便于操作员在菜单间快速导航。

---

### 多级菜单的结构设计

一个多级菜单通常设计成**树形结构**，分为多个层级。以下是一个典型的多级菜单结构：

#### 一级菜单
- 设置
- 状态
- 信息

#### 二级菜单（以“设置”为例）
- 设置
  - 显示设置
    - 亮度调节
    - 对比度调节
  - 声音设置
    - 音量调节
    - 静音设置

#### 三级菜单
- 显示设置
  - 亮度调节
    - 低亮
    - 中亮
    - 高亮

在此结构中，用户可以从一级菜单进入“设置”，选择“显示设置”后进入二级菜单，再选择“亮度调节”进入三级菜单。每一个选择步骤都明确指向一个具体操作或设置项。

---

### 多级菜单的导航方式

多级菜单的操作依赖于一些基础的导航按键，通常包括：

1. **上/下键**：用于在同一层级的菜单项中移动选择。
2. **确认键**：进入子菜单或确认当前选择并执行对应的功能。
3. **返回键**：返回到上一级菜单，帮助用户逐步回退。

通过这些导航按键，用户可以在多级菜单的不同层级之间自由切换，从而快速找到需要的功能。

---

### 多级菜单设计的关键点

1. **清晰的层次结构**：根据功能的重要性和关联性进行分层设计，使用户能清晰地理解菜单结构。
2. **简洁的标题描述**：菜单项的标题要尽量简洁明了，以便用户迅速识别各项功能。
3. **合理的返回机制**：在嵌入式设备上，返回机制需要清晰明确，避免用户在操作时产生困惑。
4. **层级深度控制**：层级不要过深，过深的菜单会影响用户体验，用户需要多次按键才能到达某个选项。

---

### 多级菜单的优势

1. **提升用户体验**：多级菜单可以在有限的显示屏上，逐步引导用户找到目标功能，使得用户体验更友好。
2. **信息可扩展性强**：随着设备功能增加，可以在多级菜单中灵活增减各个层级的功能项。
3. **内存资源利用率高**：在嵌入式系统中，不需要全部显示所有菜单项，仅当前层级的菜单项被加载到显示区中，大幅降低了内存资源的占用。
4. **维护便捷**：多级菜单的设计使得菜单项可以根据需求方便地增加或删除，便于系统维护和功能更新。

---

在嵌入式系统中，多级菜单通常使用**链表**来实现，主要是因为链表在动态数据管理、内存利用和结构灵活性方面的优势，使其特别适合用于资源有限的系统。下面详细分析一下原因：

### 1. 动态结构和灵活性

链表是一种**动态数据结构**，菜单项可以随时增加或删除，而无需调整整个数据结构的内存分布。相比之下，数组需要在定义时确定大小，后续增删项可能需要重新分配内存。而链表的节点可以灵活地插入或移除，不会影响到其他节点的位置。这种特性对于**多级菜单的层级和项目变动**非常有用，比如在不同模式下显示不同的菜单项或根据设备状态动态调整菜单。

### 2. 节省内存空间

在嵌入式系统中，**内存资源通常非常有限**。链表通过指针的方式连接节点，仅为当前菜单层级分配内存，避免了分配过多不必要的空间。每个节点的内存大小只包含当前菜单项的数据和指向下一节点的指针，而不像数组那样需要为所有节点预留空间。这在只需显示部分菜单的场景下尤为节省内存。

### 3. 易于实现多级层次结构

链表可以轻松实现**树形结构**，每个菜单项（节点）可以包含指向下一级子菜单的指针。例如，每个节点可以包含一个指向“下一个同级菜单项”的指针（如`next`），以及一个指向“子菜单”的指针（如`subMenu`）。这种结构允许多级菜单的任意层次结构和嵌套关系，便于构建复杂的菜单层级。 

对于需要动态管理层次结构的嵌入式系统来说，链表的这种特性非常适合。例如，主菜单项可以在不影响子菜单的情况下独立修改，每个子菜单也是独立的链表。

### 4. 更高效的插入和删除操作

多级菜单在开发过程中往往需要不断调整菜单项的位置和数量，例如根据用户需求增加新功能、隐藏或删除某些选项。链表的**插入和删除操作效率更高**，只需要调整指针即可完成操作，不需要移动其他节点。这在资源紧张的系统中更为高效，相比数组操作需要频繁移动数据，链表的效率更高。

### 5. 简化菜单导航逻辑

链表天然的**前后指针**结构，使得菜单导航更为简单。用户通过上下键在菜单项中移动时，只需要调整指针指向的节点，而不需要在整个数据结构中进行索引或查找操作。这种前后链接的特性大大简化了**菜单的导航逻辑**，便于快速实现菜单循环显示（即首尾相连的菜单）。

### 6. 较好的扩展性

链表结构具有较强的**扩展性**。随着系统功能增加，可以轻松地在菜单中添加新项，不会破坏现有结构。对于长期维护的嵌入式项目，链表的扩展性使得菜单结构的维护和升级更加简单。

```c
typedef struct MenuItem {
    char* title;                 // 菜单标题
    struct MenuItem* next;       // 指向下一个菜单项
    struct MenuItem* subMenu;    // 指向子菜单
    void (*action)();            // 执行操作的函数
} MenuItem;
```

使用这种结构后，一级菜单、二级菜单和三级菜单的层次关系可以轻松表示，每次用户选择菜单项时，只需根据`next`和`subMenu`指针调整显示内容即可。

链表（Linked List）是一种**数据存储结构**，类似于一串串起来的“项链”，每个项链珠子里不仅装着数据，还连接到下一个珠子。这种结构非常灵活，可以轻松地添加、删除和移动珠子，而不像数组那样需要固定的大小。链表尤其适合在数据需要**动态变化**的情况下使用，比如多级菜单、动态队列等。

### 什么是链表？

【【动画演示】链表详解及其底层机制 C语言】 https://www.bilibili.com/video/BV1S64y1W7u5/?share_source=copy_web&vd_source=6b05aba58b363b9a543633dd8d43ce1d

链表由**一系列节点（Node）**组成，每个节点包含两个部分：

1. **数据部分**：用来存储数据，比如一个数字、一个字符或一个对象。
2. **指针部分**：用来连接下一个节点，就像项链中的锁链一样，把各个节点链接在一起。

我们一般从**第一个节点**（叫“头结点”）开始，一直沿着“指针”走，直到找到**最后一个节点**（它的指针是空的，表示链表结束）。所以链表是一种**线性结构**，类似于火车的一节节车厢，每节车厢都知道下一节车厢在哪里。

### 链表的基本类型

链表有几种常见的类型：

1. **单向链表**：每个节点只指向下一个节点，就像一列单向行驶的火车。
2. **双向链表**：每个节点有两个指针，分别指向前一个和后一个节点，可以双向行走。
3. **循环链表**：最后一个节点指向第一个节点，形成一个环，可以循环走动。

### 链表与数组的区别

|     特性      |        数组        |        链表        |
| :-----------: | :----------------: | :----------------: |
|     大小      |        固定        |  动态，可随时增减  |
| 插入/删除速度 | 慢（需要移动元素） | 快（调整指针即可） |
|   访问速度    | 快（可以直接访问） | 慢（需要逐个查找） |
|   内存结构    |       连续的       | 非连续的，分散存储 |

链表特别适合在**不确定数据个数**或**数据经常变动**的情况下使用。

### 如何简单理解链表的工作原理

我们来想象一个现实中的例子——**书签链表**。假设我们有很多书，每本书的封面里贴了一个书签，书签上有两个信息：书名和下一本书的名字。只要找到第一个书签，我们就可以根据书签上的指示找到第二本书，再从第二本书找到第三本书……这样一步步找到所有书。

---

### 构建一本“书链”

我们会使用链表实现一个书链，其中每本书的书签包含**书名**和**指向下一本书的指针**。

---

### 第一步：定义节点结构

我们首先要定义“书签”这个结构。在链表中，每一个“书签”就叫做一个“节点”。每个节点都包含两个部分：

1. **书名**：即数据，表示书的名字。
2. **指针**：指向下一本书（节点）的指针。

用代码来定义一个节点结构，可以写成这样：

```c
#include <stdio.h>
#include <stdlib.h>

// 定义一个结构体，代表链表的“节点”
typedef struct Node 
{
    char* bookName;           // 书的名字（存放数据）
    struct Node* next;        // 指向下一本书的指针
} Node;
```

在这段代码中，我们做了以下事情：

- `typedef struct Node { ... } Node;`：定义了一个新的结构体类型`Node`，这个`Node`是链表的基本单位。
- `char* bookName;`：表示书名，用字符指针`char*`来存储书的名字。
- `struct Node* next;`：这是一个指针，用来存储“下一本书”的位置，表示链表的链接。

### 第二步：创建一个节点

我们需要一个函数来**创建一个节点**。每次创建节点时，给它分配一段内存来保存书名和指向下一本书的指针（初始状态下这个指针指向`NULL`，表示它是最后一本书）。

代码如下：

```c
Node* createNode(char* name) 
{
    Node* newNode = (Node*)malloc(sizeof(Node));  // 分配一个Node大小的内存
    newNode->bookName = name;                     // 存储书名
    newNode->next = NULL;                         // 暂时没有下一本书，所以指向NULL
    return newNode;                               // 返回新创建的节点
}
```

解释：

1. `Node* newNode = (Node*)malloc(sizeof(Node));`：给新节点分配内存。`malloc`是分配内存的函数，这里我们为新节点分配`Node`大小的内存空间。
2. `newNode->bookName = name;`：将传入的书名`name`存储到`newNode`节点的`bookName`中。
3. `newNode->next = NULL;`：初始状态下，节点没有下一本书，所以`next`指向`NULL`。
4. `return newNode;`：返回新创建的节点。

这个函数的作用是**创建一个新的节点，并存储书名和指针**。

### 第三步：在链表中插入一本新书

接下来，我们需要一个函数来**在链表末尾添加新节点**（即新书）。我们可以从第一本书开始，一本一本地找到最后一本书，然后把最后一本书的“指针”指向新创建的书，完成插入。

代码如下：

```c
void insertNode(Node* head, char* name) 
{
    Node* current = head;                 // 从头结点开始
    while (current->next != NULL) 
    {      								 // 一直找到最后一本书
        current = current->next;          // 移动到下一本书
    }
    current->next = createNode(name);     // 最后一本书指向新书（新节点）
}
```

解释：

1. `Node* current = head;`：定义一个指针`current`，从头结点（第一本书）开始。
2. `while (current->next != NULL) { ... }`：循环找到最后一本书。只要`current->next`不是`NULL`，就继续找下去。
3. `current = current->next;`：把`current`移到下一本书，不断向链表末尾移动。
4. `current->next = createNode(name);`：找到最后一本书后，将最后一本书的`next`指向新创建的节点，即将新书放在链表末尾。

这个函数的作用是**找到链表的末尾，将新书添加到链表中**。

### 第四步：打印链表中的所有书

最后，我们需要一个函数来**遍历链表**，逐个打印出每本书的名字。这一步我们会从链表的头开始，依次打印每个节点的书名，直到最后一个节点。

代码如下：

```c
void printList(Node* head) 
{
    Node* current = head;                 // 从头开始
    while (current != NULL) 
    {             // 只要节点存在
        printf("%s -> ", current->bookName); // 打印书名
        current = current->next;          // 移动到下一本书
    }
    printf("NULL\n");                     // 到达链表末尾
}
```

解释：

1. `Node* current = head;`：从头节点（第一本书）开始。
2. `while (current != NULL) { ... }`：只要当前节点存在，就打印书名。
3. `printf("%s -> ", current->bookName);`：打印当前书名。
4. `current = current->next;`：移动到下一本书。
5. `printf("NULL\n");`：链表末尾是`NULL`，用来表示链表结束。

这个函数的作用是**从头开始打印链表中所有书名**，直到链表结束。

我们创建链表并插入几本书，然后打印整个链表。

{

    insertNode(head, "To Kill a Mockingbird");
    insertNode(head, "The Catcher in the Rye");
    
    // 打印链表

> ### 1. 菜单项类型定义
>
> 为了支持多种不同的菜单项类型，我们使用了**枚举**定义。这样可以根据菜单项的类型（如“执行动作”或“布尔开关”）来决定其行为。
>
> ```c
> typedef enum 
> {
>     MENU_ITEM_ACTION,  // 动作菜单项，用于执行特定功能
>     MENU_ITEM_SUBMENU, // 子菜单项，用于进入子菜单
>     MENU_ITEM_BOOLEAN, // 布尔类型菜单项，可切换状态（开/关）
>     MENU_ITEM_NUMERIC  // 数值调节菜单项，允许调节数值范围
> } MenuItemType;
> ```
>
> #### 知识点：
> - **枚举（enum）**：枚举为一组相关的常量提供了有意义的名称。这里的`MenuItemType`定义了多种菜单项类型，使代码更具可读性。
>   
>
> **作用**：通过枚举定义，我们可以明确每种菜单项的作用和行为，便于后续在代码中根据类型判断执行相应操作。
>
> ---
>
> ### 2. 菜单项结构体定义
>
> 每一个菜单项都是一个节点（结构体），结构体中包含了菜单项的**名称**、**类型**、根据不同类型的数据内容（如函数指针或子菜单指针）、以及前后链接指针。
>
> ```c
> typedef struct MenuItem 
> {
>     char *name;                     // 菜单项的名称，用于显示
>     MenuItemType type;              // 菜单项类型（动作、子菜单、布尔、数值）
>     
>     // 联合体，根据不同的菜单项类型存储不同的数据
>     union 
>     {
>         void (*action)(void);           // 动作菜单项的回调函数指针
>         struct MenuItem *submenu;       // 子菜单的指针
>         struct 
>         {                                // 布尔类型菜单项的数据
>             uint8_t *value;             // 布尔项的值指针
>             void (*toggle_action)(void);// 布尔项的切换回调函数
>         } boolean_item;
>         struct 
>         {                                // 数值调节菜单项的数据
>             int *value;                 // 数值项的值指针
>             int min;                    // 数值项的最小值
>             int max;                    // 数值项的最大值
>             void (*adjust_action)(int); // 数值项的调节回调函数
>         } numeric_item;
>     } menu_item;
>     
>     struct MenuItem *next;           // 指向下一个菜单项的指针
>     struct MenuItem *prev;           // 指向上一个菜单项的指针
> } MenuItem;
> ```
>
> #### 知识点：
> - **联合体（union）**：联合体允许在同一内存位置存储不同的数据类型，这样不同类型的菜单项可以共享一个结构体，而不会占用多余内存。
> - **函数指针**：例如`void (*action)(void);`是一个函数指针，用于绑定一个函数，以便在选择菜单项时可以调用特定操作。
>
> **作用**：通过`union`实现了菜单项数据的多样性；每种菜单项在结构上共享一个`union`空间，但可以根据类型来存储不同的数据或指针。这一设计让菜单项结构体更具扩展性和灵活性。
>
> ---
>
> ### 3. 创建菜单项的函数
>
> `create_menu_item`函数用于动态分配一个新的菜单项，并根据类型初始化其数据字段。这是实现菜单项动态创建的关键函数。
>
> ```c
> MenuItem *create_menu_item(const char *name, 
>                            MenuItemType type, 
>                            void (*action)(void), 
>                            MenuItem *submenu) 
> {
>     // 为新菜单项分配内存空间
>     MenuItem *item = (MenuItem *)malloc(sizeof(MenuItem));
>     if (!item) 
>     {
>         return NULL; // 内存分配失败时返回 NULL
>     }
>     
>     // 使用 strdup 复制菜单项名称
>     item->name = strdup(name); 
>     item->type = type;         // 设置菜单项类型
> 
>     // 根据菜单项类型，初始化数据
>     if (type == MENU_ITEM_ACTION) 
>     {
>         item->menu_item.action = action; // 为动作类型菜单设置回调函数
>     } 
>     else if (type == MENU_ITEM_SUBMENU) 
>     {
>         item->menu_item.submenu = submenu; // 为子菜单类型设置子菜单指针
>     } 
>     else if (type == MENU_ITEM_BOOLEAN) 
>     {
>         item->menu_item.boolean_item.value = NULL;         // 布尔项的值指针初始为空
>         item->menu_item.boolean_item.toggle_action = NULL; // 布尔项的切换动作初始为空
>     } 
>     else if (type == MENU_ITEM_NUMERIC) 
>     {
>         item->menu_item.numeric_item.value = NULL;         // 数值项的值指针初始为空
>         item->menu_item.numeric_item.min = 0;              // 设置数值项的最小值
>         item->menu_item.numeric_item.max = 100;            // 设置数值项的最大值
>         item->menu_item.numeric_item.adjust_action = NULL; // 数值项的调节动作初始为空
>     }
> 
>     // 初始化链表的前后指针
>     item->next = NULL;
>     item->prev = NULL;
>     
>     return item; // 返回新创建的菜单项指针
> }
> ```
>
> #### 知识点：
> - **动态内存分配（malloc）**：使用`malloc`在运行时分配内存空间，这样可以在程序运行时灵活创建菜单项。
> - **字符串复制（strdup）**：`strdup`是C语言的标准库函数，用于复制字符串，这样菜单项名称不会受到外部字符串变量的影响。
>
> **作用**：这个函数是动态生成菜单项的核心，它确保每个菜单项的名称、类型和数据都能被初始化。对于不同类型的数据，根据`type`设置不同的`union`字段。
>
> ---
>
> ### 4. 链表结构管理
>
> 菜单项使用**双向链表**存储，`add_menu_item`函数用于将新的菜单项追加到链表末尾。
>
> ```c
> void add_menu_item(MenuItem **head, 
>                    MenuItem *item) 
> {
>     // 如果链表为空，将新项作为头节点
>     if (*head == NULL) 
>     {
>         *head = item; 
>     } 
>     else 
>     {
>         // 遍历链表，找到链表的末尾
>         MenuItem *temp = *head;
>         while (temp->next != NULL) 
>         {
>             temp = temp->next; // 移动到下一个节点
>         }
>         
>         // 在链表末尾添加新节点
>         temp->next = item; 
>         item->prev = temp; // 设置新节点的前指针为最后一个节点
>     }
> }
> ```
>
> #### 知识点：
> - **双向链表**：双向链表的每个节点有两个指针，分别指向前一个和后一个节点，便于在菜单项之间双向导航。
> - **指针操作**：链表中通过指针连接每个菜单项节点，增删节点时不需要移动整个链表的数据，只需更新指针。
>
> **作用**：链表结构支持动态扩展，每次添加新的菜单项时只需将其加入链表末尾。双向链表的设计可以支持用户在菜单项之间前后切换。
>
> ---
>
> ### 5. 菜单导航和堆栈管理
>
> `auto_menu_handle_key`函数负责处理用户的按键输入，实现菜单项之间的导航、进入子菜单和返回父菜单的功能。
>
> ```c
> void auto_menu_handle_key(uint8_t key) 
> {
>     switch (key) 
>     {
>     case 1: // 上移
>         if (current_menu && current_menu->prev != NULL) 
>         {
>             current_menu = current_menu->prev; // 移动到前一个菜单项
>         }
>         break;
>     case 2: // 下移
>         if (current_menu && current_menu->next != NULL) 
>         {
>             current_menu = current_menu->next; // 移动到下一个菜单项
>         }
>         break;
>     case 3: // 确认键：进入子菜单或执行动作
>         if (current_menu && current_menu->type == MENU_ITEM_ACTION && current_menu->menu_item.action) 
>         {
>             current_menu->menu_item.action(); // 执行动作
>         } 
>         else if (current_menu && current_menu->type == MENU_ITEM_SUBMENU) 
>         {
>             if (parent_menu_stack_index < MENU_STACK_SIZE - 1) 
>             {
>                 parent_menu_stack[++parent_menu_stack_index] = current_menu; // 当前菜单压入堆栈
>                 current_menu = current_menu->menu_item.submenu; // 进入子菜单
>             }
>         }
>         break;
>     case 4: // 返回键
>         if (parent_menu_stack_index >= 0) 
>         {
>             current_menu =
> 
>  parent_menu_stack[parent_menu_stack_index--]; // 弹出父菜单
>         }
>         break;
>     }
>     
>     auto_menu_display(); // 刷新显示
> }
> ```
>
> #### 知识点：
> - **堆栈（Stack）**：堆栈是一种后进先出（LIFO）的数据结构，用于保存当前的菜单层级信息，支持用户返回到上一级菜单。
> - **条件判断**：根据`current_menu`的指针和`type`，确定当前要执行的操作，是移动、进入子菜单还是执行动作。
>
> **作用**：通过该函数实现了用户在菜单中的导航逻辑，使得用户可以自由地在菜单项之间移动。堆栈用于保存多级菜单层次，支持进入和返回上一级菜单的操作。
>
> ---
>

>             break; // 结束显示
>         }

>         {

>         temp = temp->next; // 遍历到下一个菜单项
>         line++;
>     }
> }
> ```
>

### 多级菜单库使用指南

#### 1. 初始化菜单

在嵌入式系统中，首先需要初始化菜单系统，创建一个“根菜单”作为菜单的起始节点。`auto_menu_init`函数负责初始化整个菜单系统，将根菜单设为默认显示的菜单。

```c
void auto_menu_init(MenuItem *root_menu);
```

**示例代码**：
```c
MenuItem *root_menu;

void menu_init(void) 
{
    // 创建根菜单节点
    root_menu = create_menu_item("Main Menu", MENU_ITEM_SUBMENU, NULL, NULL);
    
    // 初始化菜单，将根菜单设为起始菜单
    auto_menu_init(root_menu);
}
```

**解释**：在此示例中，`root_menu`节点被设置为根菜单，表示菜单结构的第一级。通过`auto_menu_init(root_menu)`，根菜单被指定为起始菜单，确保用户可以从根菜单逐级进入子菜单。初始化完成后，可以开始添加其他菜单项。

---

#### 2. 创建和添加菜单项

本库支持创建不同类型的菜单项，如动作项、子菜单项、布尔开关项和数值调节项。创建菜单项使用`create_menu_item`函数，不同类型的菜单项有不同的初始化参数。创建完成后，可以将新项添加到指定菜单层中。

```c
MenuItem *create_menu_item(const char *name, MenuItemType type, void (*action)(void), MenuItem *submenu);
void add_menu_item(MenuItem **head, MenuItem *item);
```

- **动作菜单项**：适用于执行特定动作的菜单项，通过回调函数执行相关操作。
- **子菜单项**：允许进入下一级菜单，适合包含其他子项的菜单。
- **布尔开关项**：用于切换开关状态。
- **数值调节项**：用于调节值在一定范围内的参数。

**示例代码**：

1. **创建动作菜单项**：
    ```c
    void sample_action(void) 
    {
        // 定义动作，例如激活某个功能
    }
    
    MenuItem *action_item = create_menu_item("Action Item", MENU_ITEM_ACTION, sample_action, NULL);
    add_menu_item(&root_menu->menu_item.submenu, action_item);
    ```
    **解释**：定义了一个动作函数`sample_action`，当用户选择`Action Item`菜单项时，`sample_action`会被调用，完成特定动作。

2. **创建子菜单项**：
    ```c
    MenuItem *submenu = create_menu_item("SubMenu", MENU_ITEM_SUBMENU, NULL, NULL);
    add_menu_item(&root_menu->menu_item.submenu, submenu);
    ```
    **解释**：`SubMenu`是一个子菜单，进入该项将显示其下的菜单内容。此处未设置动作函数，因为子菜单不需要回调函数。

3. **创建布尔开关菜单项**：
    ```c
    void toggle_switch(void) 
    {
        // 切换开关状态
    }
    
    MenuItem *boolean_item = create_menu_item("Switch", MENU_ITEM_BOOLEAN, NULL, NULL);
    boolean_item->menu_item.boolean_item.toggle_action = toggle_switch;
    add_menu_item(&submenu->menu_item.submenu, boolean_item);
    ```
    **解释**：布尔菜单项`Switch`使用`toggle_switch`作为切换回调函数，当用户选择该菜单项时，开关状态会在“开”和“关”之间切换。

4. **创建数值调节菜单项**：
    ```c
    void adjust_brightness(int value) 
    {
        // 调整亮度
    }
    
    MenuItem *numeric_item = create_menu_item("Brightness", MENU_ITEM_NUMERIC, NULL, NULL);
    numeric_item->menu_item.numeric_item.min = 0;
    numeric_item->menu_item.numeric_item.max = 100;
    numeric_item->menu_item.numeric_item.adjust_action = adjust_brightness;
    add_menu_item(&submenu->menu_item.submenu, numeric_item);
    ```
    **解释**：`Brightness`菜单项允许用户在0到100范围内调节亮度。`adjust_brightness`函数在用户改变亮度值时被调用。

---

#### 3. 处理按键输入

在嵌入式系统中，用户可以通过按键输入来控制菜单的导航。`auto_menu_handle_key`函数根据用户按键执行不同的操作，如上下移动、进入子菜单或返回上级菜单。

```c
void auto_menu_handle_key(uint8_t key);
```

- `1`：上移
- `2`：下移
- `3`：确认（进入子菜单或执行动作）
- `4`：返回

**示例代码**：

假设使用一个`get_key`函数来检测用户输入的按键：

```c
void handle_user_input() 
{
    uint8_t key = get_key();        // 获取按键输入
    auto_menu_handle_key(key);      // 处理按键操作
}
```

**解释**：每次获取到按键输入后，将对应的按键值传递给`auto_menu_handle_key`，完成菜单项的导航操作。根据传入的键值，库会自动判断该执行的功能，包括移动菜单项、进入子菜单或返回上级菜单等。

---

#### 4. 刷新菜单显示

每次按键操作后，调用`auto_menu_display`函数更新菜单在屏幕上的显示，使当前选中项高亮显示，并刷新菜单层级。

```c
void auto_menu_display(void);
```

**示例代码**：

```c
// 在按键处理完成后刷新显示
void handle_user_input() 
{
    uint8_t key = get_key();         // 获取按键输入
    auto_menu_handle_key(key);       // 处理按键操作
    auto_menu_display();             // 刷新显示
}
```

**解释**：`auto_menu_display`负责在LCD屏幕上显示当前菜单项，并高亮当前选中项。确保每次操作后的菜单状态及时更新到用户界面。

### 拓展方法

#### 拓展 1：增加新类型的菜单项

库当前支持动作、子菜单、布尔开关和数值调节项。如果需要新增如“选择型”或“滑动条”菜单项，可以在`MenuItemType`中添加新的枚举类型，并在`MenuItem`结构体中扩展数据结构。

**实现方法**：
1. **在枚举中添加新类型**：
    ```c
    typedef enum {
        MENU_ITEM_ACTION,
        MENU_ITEM_SUBMENU,
        MENU_ITEM_BOOLEAN,
        MENU_ITEM_NUMERIC,
        MENU_ITEM_SELECT      // 新增选择菜单项类型
    } MenuItemType;
    ```
2. **在联合体中增加选择菜单项的数据结构**：
    ```c
    struct {
        int *selected_option;        // 当前选择的选项
        void (*select_action)(int);  // 回调函数
    } select_item;
    ```
3. **在`auto_menu_handle_key`函数中添加新类型的操作逻辑**：根据需求处理选择菜单项的特定行为，例如改变选中值。

#### 拓展 2：扩展菜单项显示样式

为了使菜单更加美观，可以为菜单项增加图标或自定义颜色，修改`auto_menu_display`以支持个性化显示。

**实现方法**：

1. **在`MenuItem`结构体中添加图标和颜色字段**：
    ```c
    typedef struct MenuItem {
        ...
        uint16_t icon;    // 新增图标字段
        uint16_t color;   // 新增颜色字段
    } MenuItem;
    ```
2. **在`auto_menu_display`中使用图标和颜色进行显示**：
    使用`icon`字段在LCD上绘制图标，使用`color`字段更改显示字体颜色，提升用户体验。

#### 拓展 3：支持动态删除菜单项

目前库仅支持动态添加菜单项，如果需要删除某一项，可以新增`remove_menu_item`函数，确保链表中的节点可以安全移除。

**实现方法**：

```c
void remove_menu_item(MenuItem **head, const char *name) 
{
    MenuItem *temp = *head;
    while (temp != NULL) 
    {
        if (strcmp(temp->name, name) == 0) 
        {
            if (temp->prev != NULL) 
                temp->prev->next = temp->next;
            if (temp->next != NULL) 
                temp->next->prev = temp->prev;
            if (temp == *head) 
                *head = temp->next;
            
            free(temp->name);  // 释放名称内存
            free(temp);        // 释放节点内存
            break;
        }
        temp = temp->next;
    }
}
```

**解释**：此函数通过遍历链表查找名称匹配的菜单项，找到后移除节点并释放内存，确保链表结构完整。

#### 拓展 4：支持菜单状态的保存与恢复

为了在设备掉电后保留菜单状态，可以将当前选中菜单项和参数值存储在EEPROM或Flash中。

**实现方法**：

1. **保存状态**：每次菜单项更新后，将选中项及其状态保存到EEPROM或Flash。
2. **恢复状态**：在设备启动或初始化时，从EEPROM或Flash中读取存储的菜单状态，并恢复当前菜单的显示和数据。

通过上述方法，可以确保菜单状态在断电后不丢失。
