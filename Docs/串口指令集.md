# 串口指令集 

## 1. 协议概述

本协议采用 ASCII 文本格式进行串口通信。命令解析严格区分大类前缀，格式为：
`[大类前缀] [子指令/参数]`

* **大小写敏感**：大类前缀 (`LED` / `ADC` / `DAC` / `SYS`) 必须保持全大写。
* **空包拦截**：忽略前导空格/制表符，自动过滤纯回车换行空包。
* **未知指令拦截**：未命中合法大类前缀的指令将统一回传未知错误。

---

## 2. 响应标签规范 (Log Tag)

| 标签    | 含义    | 说明                                     |
| :------ | :------ | :--------------------------------------- |
| `[CMD]` | Command | 执行动作类指令的回执 (如 Toggle, On/Off) |
| `[STS]` | Status  | 状态/数据查询类指令的回传 (如 Phase)     |
| `[WRN]` | Warning | 参数缺失或格式不完整的警告提示           |
| `[SYS]` | System  | 系统级状态或预留模块交互信息             |
| `[UNK]` | Unknown | 未知指令或非合法前缀的错误拦截           |

## 3. 指令集明细

### 3.1 LED 控制模块 (`LED`)

#### ① 翻转 LED 相位 (`toggle`)
* **语法**：`LED toggle [通道数字序列]`
* **说明**：遍历 `toggle` 后的数字，对指定 ID (1~6) 的 LED 进行相位翻转。支持单发或多通道组合发送。
* **示例**：
  
  * 发送：`LED toggle 4`
    * 响应：`[CMD] LED toggled: LED4`
  * 发送：`LED toggle 135`
    * 响应：
      ```text
      [CMD] LED toggled: LED1
      [CMD] LED toggled: LED3
      [CMD] LED toggled: LED5
      ```
  * 发送：`LED toggle` (无数字)
    * 响应：`[WRN] LED toggle found, but no ID (1-6)!`

#### ② 查询 LED 相位偏移 (`phase`)
* **语法**：`LED phase [通道数字序列]`
* **说明**：查询指定 ID (1~6) 的 LED 相位偏移量，回传浮点值及百分比。
* **示例**：
  * 发送：`LED phase 34`
    * 响应：
      ```text
      [STS] LED3 Phase Offset: 0.38 (38%)
      [STS] LED4 Phase Offset: 0.04 (4%)
      ```

#### ③ LED 电源/黑屏控制 (`on` / `off`)
* **语法**：`LED on` 或 `LED off`
* **说明**：全局开启或切断 LED 输出（进入 Blackout 状态）。
* **示例**：
  * 发送：`LED off`
    * 响应：`[CMD] LED: OFFLINE (Blackout)`
  * 发送：`LED on`
    * 响应：`[CMD] LED: ONLINE`

---

### 3.2 ADC 模数转换模块 (`ADC`)

* **状态**：接口预留中
* **语法**：`ADC [子指令]`
* **示例**：
  * 发送：`ADC Read`
    * 响应：`[STS] ADC Sub-command received: Read`

---

### 3.3 DAC 数模转换模块 (`DAC`)

* **语法**：`DAC [动作] [参数]`
* **说明**：子指令关键字（`set` / `get` / `FSR` / `period`）同样区分大小写。

#### ① 设置波形满量程 FSR (`set FSR`)
* **语法**：`DAC set FSR [数值]`
* **说明**：设置 DAC 输出的满量程 FSR，范围 0~3300。超出范围时自动夹紧到边界值。
* **示例**：
  * 发送：`DAC set FSR 1500`
    * 响应：`[CMD] DAC FSR: 1500`
  * 发送：`DAC set FSR 9999`
    * 响应：`[CMD] DAC FSR: 3300`

#### ② 设置波形周期 (`set period`)
* **语法**：`DAC set period [数值]`
* **说明**：设置波形周期，单位 ms，范围 5~5400。超出范围时自动夹紧到边界值。设置后会同步 ADC 采样窗口。
* **示例**：
  * 发送：`DAC set period 2000`
    * 响应：`[CMD] DAC period: 2000`
  * 发送：`DAC set period 0`
    * 响应：`[CMD] DAC period: 5`

#### ③ 查询 FSR (`get FSR`)
* **语法**：`DAC get FSR`
* **示例**：
  * 发送：`DAC get FSR`
    * 响应：`[STS] DAC FSR: 1500`

#### ④ 查询周期 (`get period`)
* **语法**：`DAC get period`
* **示例**：
  * 发送：`DAC get period`
    * 响应：`[STS] DAC period: 2000`

---

### 3.4 SYS 系统模块 (`SYS`)

* **状态**：接口预留中
* **语法**：`SYS [子指令]`
* **示例**：
  * 发送：`SYS Reset`
    * 响应：`[SYS] SYS Sub-command received: Reset`

---

## 4. 错误处理示例

* **未带合法前缀**：
  * 发送：`toggle 4236`
  * 响应：`[UNK] Invalid category prefix: toggle 4236`
* **命中前缀但缺动作**：
  * 发送：`LED`
  * 响应：`[WRN] LED command recognized, but missing valid action (Toggle/Phase/On/Off)!`
