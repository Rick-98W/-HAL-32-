# 串口指令集

## 1. 协议概述

本协议采用 ASCII 文本格式进行串口通信（115200 8N1）。命令解析严格区分大类前缀，格式为：
`[大类前缀] [子指令/参数]`

* **大小写敏感**：大类前缀 (`LED` / `ADC` / `DAC` / `SYS`) 必须保持全大写；子指令关键字（如 `set` / `get` / `FSR` / `period`）同样区分大小写。
* **指令结束符**：每条指令以 `;` 或 `\n` 结束，`\r` 会被忽略。因此 `LED toggle 1;LED toggle 2` 会被当作两条指令。
* **空包拦截**：忽略前导空格/制表符，自动过滤纯回车换行空包。
* **回显**：每条非空指令在执行前都会先回显一行 `Command Received: <指令>`（已去掉前导空白）。
* **超长拦截**：单条指令超过 255 字节时整条丢弃，不做任何回应。
* **未知指令拦截**：未命中合法大类前缀的指令将统一回传 `[UNK]` 提示。
* **子指令匹配**：子指令按关键字包含关系识别（即只要文本中包含关键字就命中），因此 `DAC set wave type sinusoidal` 与 `DAC set wave type sin` 效果相同。

---

## 2. 响应标签规范 (Log Tag)

| 标签    | 含义    | 说明                                                       |
| :------ | :------ | :--------------------------------------------------------- |
| `[CMD]` | Command | 执行动作类指令的回执 (如 set / toggle / on / off / analyze) |
| `[STS]` | Status  | 状态/数据查询类指令的回传 (如 get / phase)                  |
| `[WRN]` | Warning | 参数缺失、格式不完整或指令不合法的警告提示；TX 缓冲区满丢数据的提示也用此标签 |
| `[ERR]` | Error   | 内部资源分配失败（如内存池耗尽）                            |
| `[SYS]` | System  | 系统级状态或预留模块交互信息                               |
| `[UNK]` | Unknown | 未知指令或非合法前缀的错误拦截                             |

## 3. 指令速查表

| 模块 | 指令 | 作用 |
| :--- | :--- | :--- |
| LED | `LED toggle <1-6...>` | 翻转指定 LED 的相位 |
| LED | `LED phase <1-6...>` | 查询指定 LED 的相位偏移 |
| LED | `LED on` / `LED off` | 恢复 / 切断 LED 输出（Blackout） |
| ADC | `ADC analyze` | 对当前 ADC 窗口做一次波形分析 |
| ADC | `ADC set ratio double` / `ADC set ratio single` | 设置采样倍率 |
| ADC | `ADC get ratio` | 查询采样倍率 |
| ADC | `ADC get freq` / `get period` / `get vpp` / `get type` | 查询波形分析结果 |
| ADC | `ADC wave export` | 逐行导出 ADC 采样窗口（mV） |
| DAC | `DAC set FSR <n>` | 设置满量程，0~3300 |
| DAC | `DAC set period <n>` | 设置周期（ms），5~5400 |
| DAC | `DAC set wave type <sin/tri/saw>` | 设置输出波形 |
| DAC | `DAC get FSR` / `get period` / `get wave type` | 查询 DAC 当前设置 |
| SYS | `SYS <任意>` | 预留，仅回显 |

## 4. 指令集明细

### 4.1 LED 控制模块 (`LED`)

#### ① 翻转 LED 相位 (`toggle`)
* **语法**：`LED toggle [通道数字序列]`
* **说明**：遍历 `toggle` 后的数字，对指定 ID (1~6) 的 LED 进行相位翻转。支持单发或多通道组合发送。其它数字会被忽略。
* **示例**：
  * 发送：`LED toggle 4`
    * 响应：`[CMD] LED toggled: LED4`
  * 发送：`LED toggle 135`
    * 响应：
      ```text
      [CMD] LED toggled: LED1
      [CMD] LED toggled: LED3
      [CMD] LED toggled: LED5
      ```
  * 发送：`LED toggle` (无数字) 或 `LED toggle 7` (无合法 ID)
    * 响应：`[WRN] LED toggle found, but no ID (1-6)!`

#### ② 查询 LED 相位偏移 (`phase`)
* **语法**：`LED phase [通道数字序列]`
* **说明**：查询指定 ID (1~6) 的 LED 相位偏移量，回传浮点值及百分比。
* **示例**：
  * 发送：`LED phase 34`
    * 响应：
      ```text
      [STS] LED3 Phase Offset: 0.38 (38%)
      [STS] LED4 Phase Offset: 0.04 (4%)
      ```
  * 发送：`LED phase` (无合法 ID)
    * 响应：`[WRN] LED phase found, but no ID (1-6)!`

#### ③ LED 电源/黑屏控制 (`on` / `off`)
* **语法**：`LED on` 或 `LED off`
* **说明**：全局开启或切断 LED 输出（进入 Blackout 状态）。
* **示例**：
  * 发送：`LED off`
    * 响应：`[CMD] LED: OFFLINE (Blackout)`
  * 发送：`LED on`
    * 响应：`[CMD] LED: ONLINE`

#### ④ 不合法的 LED 子指令
* **示例**：
  * 发送：`LED` 或 `LED blink`
  * 响应：`[WRN] LED command recognized, but missing valid action (toggle/phase/on/off)!`

### 4.2 ADC 模数转换模块 (`ADC`)

ADC 采样窗口由 DAC 的输出驱动：采样率跟随 DAC 周期，DAC 的 FSR / 周期 / 波形变化都会使窗口重新开始采集。窗口长度为 `single` 时 512 点、`double` 时 1024 点。

#### ① 波形分析 (`analyze`)
* **语法**：`ADC analyze`
* **说明**：对当前窗口做一次分析并缓存结果。窗口未采满时不会分析。
* **示例**：
  * 发送：`ADC analyze`
    * 响应：`[CMD] ADC wave analyzed`
  * 窗口未采满（例如刚改过 DAC 设置后立即发送）：
    * 响应：`waveform: window not full, skip`
  * 分析所需内存不足或快照失败：
    * 响应：`[ERR] waveform: memory allocate failed, skip` 或 `waveform: snapshot failed, skip`

#### ② 设置采样倍率 (`set ratio`)
* **语法**：`ADC set ratio double` 或 `ADC set ratio single`
* **说明**：`double` 为高倍率（采样点加倍，窗口 1024 点），`single` 为单倍率（窗口 512 点）。设置值变化时会重新开始采集。
* **示例**：
  * 发送：`ADC set ratio double`
    * 响应：`[CMD] ADC ratio: double`
  * 发送：`ADC set ratio single`
    * 响应：`[CMD] ADC ratio: single`

#### ③ 查询采样倍率 (`get ratio`)
* **语法**：`ADC get ratio`
* **示例**：
  * 发送：`ADC get ratio`
    * 响应：`[STS] ADC ratio: double`

#### ④ 查询分析结果 (`get freq` / `get period` / `get vpp` / `get type`)
* **语法**：`ADC get freq`、`ADC get period`、`ADC get vpp`、`ADC get type`
* **说明**：返回最近一次分析的结果。如果结果已过期（分析之后 DAC 或 ADC 的设置有过变化），会先自动重新分析一次，再返回新值。自动分析失败时只会打印分析失败的那一行，不会打印结果。
* **示例**：
  * 发送：`ADC get freq`
    * 响应：`[STS] ADC freq: 1000.0 Hz`
  * 发送：`ADC get period`
    * 响应：`[STS] ADC period: 1.000 ms`
  * 发送：`ADC get vpp`
    * 响应：`[STS] ADC vpp: 3000 mV`
  * 发送：`ADC get type`
    * 响应：`[STS] ADC wave type: SINE`
    * 类型取值：`SINE` / `SQR` / `TRI` / `SAW` / `DC` / `UNKNOWN`

#### ⑤ 导出采样窗口 (`wave export`)
* **语法**：`ADC wave export`
* **说明**：把当前窗口的采样值（mV）逐行输出到串口，每 1 ms 输出一行，格式为 `序号.: 值`。输出条数与窗口长度一致（single 为 512 行，double 为 1024 行）。
* **示例**：
  * 发送：`ADC wave export`
    * 响应（节选）：
      ```text
      0.: 1650
      1.: 1712
      2.: 1768
      ...
      ```
* **异常**：
  * 窗口未采满：`waveform: window not full, skip`
  * 内存不足：`[ERR] memory allocate failed, export stopped`
  * 快照失败：`waveform: snapshot failed, export stopped`
  * 上一次导出尚未结束时再次发送：**静默忽略，无回应**

#### ⑥ 不合法的 ADC 子指令
* **示例**：
  * 发送：`ADC` 或 `ADC read`
  * 响应：`[WRN] ADC command recognized, but missing valid action (analyze/set ratio/get ratio/get freq/get period/get vpp/get type/wave export)!`

### 4.3 DAC 数模转换模块 (`DAC`)

#### ① 设置波形满量程 FSR (`set FSR`)
* **语法**：`DAC set FSR [数值]`
* **说明**：设置 DAC 输出的满量程 FSR，范围 0~3300。超出范围时自动夹紧到边界值。负数同样夹紧到 0。FSR 实际变化后 ADC 采样窗口会重新开始。
* **示例**：
  * 发送：`DAC set FSR 1500`
    * 响应：`[CMD] DAC FSR: 1500`
  * 发送：`DAC set FSR 9999`
    * 响应：`[CMD] DAC FSR: 3300`

#### ② 设置波形周期 (`set period`)
* **语法**：`DAC set period [数值]`
* **说明**：设置波形周期，单位 ms，范围 5~5400。超出范围时自动夹紧到边界值。周期实际变化后 ADC 采样率同步变化，采样窗口重新开始。
* **示例**：
  * 发送：`DAC set period 2000`
    * 响应：`[CMD] DAC period: 2000`
  * 发送：`DAC set period 0`
    * 响应：`[CMD] DAC period: 5`

#### ③ 设置波形类型 (`set wave type`)
* **语法**：`DAC set wave type [sin / tri / saw]`
* **说明**：设置输出波形。按关键字识别，`sin` 对应正弦波（sinusoidal），`tri` 对应三角波（triangular），`saw` 对应锯齿波（sawtooth）。也可以写全称。波形实际变化后 ADC 采样窗口会重新开始。
* **示例**：
  * 发送：`DAC set wave type tri`
    * 响应：`[CMD] DAC wave type: triangular`
  * 发送：`DAC set wave type sawtooth`
    * 响应：`[CMD] DAC wave type: sawtooth`
  * 发送：`DAC set wave type square`（无法识别的波形名）
    * 响应：`[WRN] DAC wave type not recognized, use sin/tri/saw!`

#### ④ 查询 FSR (`get FSR`)
* **语法**：`DAC get FSR`
* **示例**：
  * 发送：`DAC get FSR`
    * 响应：`[STS] DAC FSR: 1500`

#### ⑤ 查询周期 (`get period`)
* **语法**：`DAC get period`
* **示例**：
  * 发送：`DAC get period`
    * 响应：`[STS] DAC period: 2000`

#### ⑥ 查询波形类型 (`get wave type`)
* **语法**：`DAC get wave type`
* **示例**：
  * 发送：`DAC get wave type`
    * 响应：`[STS] DAC wave type: sinusoidal`
    * 取值：`sinusoidal` / `triangular` / `sawtooth`

#### ⑦ 不合法的 DAC 子指令
* **示例**：
  * 发送：`DAC` 或 `DAC set FSR abc`
  * 响应：`[WRN] DAC command recognized, but missing valid action (set FSR/set period/set wave type/get FSR/get period/get wave type)!`
* **注意**：`set FSR` 和 `set period` 要求关键字与数值之间有空格，`DAC set FSR1500` 会被判为不合法。

### 4.4 SYS 系统模块 (`SYS`)

* **状态**：接口预留中，目前只回显
* **语法**：`SYS [子指令]`
* **示例**：
  * 发送：`SYS Reset`
    * 响应：`[SYS] SYS Sub-command received: Reset`

## 5. 错误处理示例

* **未带合法前缀**：
  * 发送：`toggle 4236`
  * 响应：
    ```text
    Command Received: toggle 4236
    [UNK] Invalid category prefix: toggle 4236
    ```
* **命中前缀但缺动作**：
  * 发送：`LED`
  * 响应：
    ```text
    Command Received: LED
    [WRN] LED command recognized, but missing valid action (toggle/phase/on/off)!
    ```
* **指令超过 255 字节**：整条丢弃，无任何回应。
* **TX 缓冲区满**：如果输出速度超过串口发送能力，缓冲区满时多余字节会被丢弃，之后会打印一行：
  `[WRN] TX buffer full, N bytes dropped`
