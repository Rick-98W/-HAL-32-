# STM32F429 嵌入式综合练习项目

基于 STM32F429（HAL 库、裸机主循环）的个人练习项目。目标是把 DAC 波形输出、ADC 采样、波形分析、串口指令、按键旋钮、OLED 菜单和 LED 输出串成一个完整的小系统。

**项目仍在开发中**。下面只列出已经实现并能在开发板上运行的部分，未完成的内容放在最后的「规划」里。

## 当前状态

- 状态：开发中（个人练习项目）
- 运行方式：裸机主循环，由轻量调度器按周期轮询各任务
- 已完成：DAC 波形输出、ADC 窗口采样、波形分析、串口导出、ICAP 占空比测量（启动已接入，输出待确认）、串口指令控制、按键与旋钮输入、OLED 菜单、六路 LED 相位控制
- 未完成：见「规划」和「已知限制」

## 已实现功能

| 模块      | 说明                                                         |
| :-------- | :----------------------------------------------------------- |
| DAC 输出  | 可通过串口或菜单设置满量程 FSR（0~3300）、周期（5~5400 ms）和波形（正弦 / 三角 / 锯齿）。改动后通过回调通知 ADC |
| ADC 采样  | TIM3 触发 ADC1，DMA 循环写入 1024 点环形缓冲，采样率跟随 DAC 周期，支持单倍（512 点）和双倍（1024 点）切换 |
| 波形分析  | 对 ADC 快照调用分析库，输出频率、周期、峰峰值、波形类型。结果带「代数」标记，窗口重置后自动判定过期 |
| 串口导出  | 把采样窗口逐行输出到串口（每 1 ms 一行），通过通用导出模块完成，不阻塞主循环 |
| ICAP 测量 | TIM9 / TIM12 输入捕获，计算两路 PWM 的占空比                 |
| 串口指令  | 115200 8N1，ASCII 指令，覆盖 LED、ADC、DAC、SYS 四个大类，带回显和统一的 `[CMD]` `[STS]` `[WRN]` 标签 |
| 按键      | ebtn 消抖，单击映射为菜单导航（上 / 下 / 确认 / 返回）       |
| 旋钮      | ADC2 多次采样求均值，死区滤波，只在值编辑状态下生效          |
| OLED 菜单 | 基于链表的菜单树，支持子页、动作、数值编辑和参数页           |
| LED       | 六路 LED 相位输出，支持翻转、查询相位偏移、全局黑屏          |
| 内存池    | 8 KB 固定块内存池（32 / 128 / 512 / 2048 字节），代替堆，分配失败时返回 NULL |

## 系统结构

主循环只做两件事：调度器按表轮询各任务，OLED 任务每圈轮询一次。

```c
while (1) {
    scheduler_run();    // 按表轮询
    OLED_task_poll();   // OLED 每圈调用一次
}
```

调度任务表：

| 任务                 | 周期  | 作用                       |
| :------------------- | :---- | :------------------------- |
| `LED_proc`           | 1 ms  | LED 相位输出               |
| `button_proc`        | 5 ms  | 按键消抖与点击事件         |
| `USART_proc`         | 1 ms  | 发送报告、解析一条接收指令 |
| `serial_export_proc` | 1 ms  | 导出一行                   |
| `knob_proc`          | 20 ms | 读取旋钮，变化时回调菜单   |

模块之间的依赖遵循一个原则：**底层不认识上层**。DAC 只通过回调通知变化，ADC 不调用 DAC 的 getter，串口导出不知道 ADC 的存在。

## 串口指令

格式为 `[大类] [子指令] [参数]`，指令以 `;` 或换行结束。大类为 `LED` / `ADC` / `DAC` / `SYS`，全部大写。常用指令：

| 指令                                       | 作用                               |
| :----------------------------------------- | :--------------------------------- |
| `LED toggle 135`                           | 翻转 1、3、5 号 LED                |
| `LED phase 34`                             | 查询 3、4 号 LED 的相位偏移        |
| `LED on` / `LED off`                       | 恢复 / 切断 LED 输出               |
| `ADC analyze`                              | 对当前窗口做一次波形分析           |
| `ADC set ratio double` / `single`          | 设置采样倍率                       |
| `ADC get freq` / `period` / `vpp` / `type` | 查询分析结果（过期会自动重新分析） |
| `ADC wave export`                          | 逐行导出采样窗口（mV）             |
| `DAC set FSR 1500`                         | 设置满量程（0~3300）               |
| `DAC set period 2000`                      | 设置周期（5~5400 ms）              |
| `DAC set wave type sin`                    | 设置波形（sin / tri / saw）        |
| `DAC get FSR` / `period` / `wave type`     | 查询 DAC 当前设置                  |

完整格式和响应示例见 [串口指令集.md](Docs/串口指令集.md)。
